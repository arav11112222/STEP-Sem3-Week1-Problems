# STEP Semester 3 - Week 1 Problems 🚀

This repository contains my solutions for the **STEP Semester 3 Week 1 live-coding problems**.

## 📌 Problems Covered

### 1. 🎮 Rock Paper Scissors Game

A multi-round Rock-Paper-Scissors game where the computer generates a random move. The program tracks wins, losses, draws, and the player's win percentage.

**Concepts used:**

* Random number generation
* Arrays
* Loops
* Conditional statements
* Methods

### 2. 🔄 Palindrome Checker

Checks whether a given string is a palindrome using three different approaches:

* Iterative approach
* Recursive approach
* Array reversal approach

**Concepts used:**

* Strings
* Loops
* Recursion
* Character arrays
* Methods

### 3. 📊 BMI Calculator for a Team

Calculates the BMI of multiple people and classifies them as:

* Underweight
* Normal
* Overweight
* Obese

**Concepts used:**

* Arrays
* Methods
* Arithmetic operations
* Conditional statements
* Formatted output

### 4. 🔤 First Non-Repeating Character

Finds the first character in a string that appears only once.

**Example:**

```text
Input: swiss
Output: w
```

**Concepts used:**

* Arrays
* Character frequency counting
* Loops
* Strings

### 5. ↩️ Reverse Customer Name

Reverses a customer's name while keeping the original name unchanged.

**Example:**

```text
Input: Sunil
Output: linuS
```

**Concepts used:**

* String traversal
* Loops
* Methods
* Character manipulation

## 🛠️ Language Used

These programs were implemented as part of my **STEP Semester 3 Week 1 coding practice** to strengthen my understanding of Java fundamentals, including methods, arrays, strings, loops, conditional statements, recursion, and basic problem-solving.
